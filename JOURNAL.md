# October 16, 2026: Idea and design

Today i searched the web for components i could use and decided on a standard 0,96" oled display driven by a XIAO ESP32-C3 module. the whole thing will be powered by a rechargable lipo cell so it can be carried around.
I also made made some inital drawings! it mainly shows how the components would be arranged (may change)

# October 22, 2026: Firmware finished!

I wrote firmware for the tamagochi. I meant it to be pretty basic at first, but i got some help from ai and optimised it a bit. I really don't know if it'll work yet but we'll see that once i assemble the whole thing. I also updated the 3d model. I decided to use one big Lipo cell instead of 3 small ones. I even got one lying around, so i already got that covered. And with that, i think we're ready to ship!
